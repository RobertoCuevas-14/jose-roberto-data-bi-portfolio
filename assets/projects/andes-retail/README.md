# Andes Retail Commercial Performance Dashboard

## Objetivo del proyecto
Desarrollar un análisis de desempeño comercial 2024-2025 para Andes Retail Group, integrando exploración analítica y visualización ejecutiva en Power BI para monitorear ingresos, ganancia, margen, pedidos y ticket promedio.

## Datasets utilizados
El proyecto utiliza un dataset comercial de Andes Retail Group con información de ventas por periodo, país, categoría de producto, segmento de cliente, ingresos, ganancia, margen, pedidos y ticket promedio.

Campos principales utilizados:
- Fecha de pedido
- País
- Categoría de producto
- Segmento de cliente
- Ingresos
- Ganancia
- Margen
- Pedidos
- Ticket promedio

## Etapas del análisis
1. Exploración inicial de campos comerciales y estructura del dataset.
2. Preparación de datos para análisis, incluyendo revisión de tipos de datos y creación de variables de negocio.
3. Definición de preguntas ejecutivas para vistas de overview y análisis detallado.
4. Construcción de KPIs y visualizaciones en Power BI.
5. Interpretación ejecutiva usando narrativa SCQA.
6. Generación de recomendaciones para stakeholders.

1. Cargar el dataset comercial utilizado para el dashboard.
2. Validar nombres de columnas y tipos de datos.
3. Crear o revisar métricas clave: ingresos, ganancia, margen, pedidos y ticket promedio.
4. Analizar desempeño por país, categoría, segmento y estacionalidad.
5. Replicar visualizaciones en Power BI usando el archivo `.pbix` como referencia.
6. Comparar resultados contra el PDF ejecutivo exportado.

## Entregables incluidos

- Vista HTML del notebook para revisión rápida.

## Principales hallazgos
- Andes Retail generó $5.53M en ingresos y $1.94M en ganancia durante 2024-2025.
- El margen global fue de 35.1%, con rentabilidad estable entre países.
- Perú lideró la generación de ganancia.
- Deportes fue la categoría con mayores ingresos.
- El segmento Premium concentró mayor valor y ticket promedio.
- Verano presentó el mejor desempeño comercial, mientras que Invierno mostró menor generación de ingresos.
